# CGeIHC_FINAL_PROJECT
This is the final project for the CGeIHC class. It´s a virtual tour on Chautla´s Catrinerías, from Puebla. Made using C++ and OpenGL.

## IMPORTANTE
En el manual de usuario, en la sección de 'Guía Rápida', se detallan los pasos para compilar el proyecto desde Visual Studio, sin embargo, como es una entrega diferente a la del laboratorio no incluí los archivos correspondientes para una correcta ejecución, por lo que lo más probable es que no funcione. Favor de seguir únicamente los pasos de la segunda forma descrita en el documento, es decir, donde únicamente hay que ejecutar el archivo 'configuracionInicial.exe' que está dentro de la carpeta que contiene todos los recursos del proyecto, es la forma que se solicitó en el documento de requisitos para el proyecto de la materia en teoría.
